# Color

For components to be themable, they need to have access to color variables that your set in your
**theme file**. This page lists all of the variables used by this library and its example themes.

Any non-trivial project will require many more color variables than these, but they provide
a consistent naming convention that scales from simple to complex projects.

If you use sets of color scales in your CSS, you might want to map these core variables directly
to your scale values in your theme, eg `--color-bg-cta: var(--blue-700);`
